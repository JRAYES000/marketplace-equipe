# Création de page web : consignes par défaut

Valables pour toute nouvelle page web, sauf consigne contraire du demandeur. Elles s'ajoutent aux
skills métier, elles ne les remplacent pas.

## Avant d'écrire

- **Design** : charger la skill `impeccable` si elle est disponible, avant d'écrire la page.
  Sinon, appliquer le crible anti-IA ci-dessous dès la première version.
- **Textes** : les passer par `humanizer` (si disponible) avant la mise en page.

## Dans la page

- **Gras** sur les mots et phrases clés : quelques-uns par section, pas plus.
- **2 ou 3 images d'illustration** générées (`generation-images-sites` si disponible, sinon
  l'outil de génération d'images présent), en WebP compressé, texte alternatif descriptif.
- **Un seul appel à l'action**, visible sans faire défiler.
- **Bases SEO** : title, meta description, un seul H1, `alt` sur chaque image.

## Crible anti-IA (sans impeccable)

- Pas de dégradé violet-bleu générique, pas de grille de cartes à icônes emoji, pas de tout
  centré par défaut.
- Une palette assumée, tirée de la marque ; une vraie hiérarchie typographique (deux familles au
  plus, tailles contrastées).
- Une mise en page qui a un parti pris : asymétrie, rythme des sections, espace blanc voulu.
- Moins de composants, mieux finis : chaque bloc doit gagner sa place.

## Avant de livrer

- **Relecture du design** : `impeccable` `critique`, puis `bolder` si la page reste trop sage ;
  sans impeccable, relire contre le crible ci-dessus.
- **Contrôle mobile** : rendu à 375 px vérifié par capture avant de livrer.
